# KARAOKE TIN NGUYỄN

Trang landing giới thiệu dịch vụ phòng karaoke và dàn karaoke di động.

- **Truy cập ngay:** 👉 **https://karaoketinnguyen.id.vn/** 👈
- Tối ưu responsive (desktop/tablet/mobile) nhờ lưới tùy chỉnh trong `grid.css`.
- Hiệu ứng cuộn/slide đơn giản với JS thuần trong `js.js`.
- Nội dung chính: giới thiệu thiết bị, gói phòng, dàn di động và thông tin liên hệ (điện thoại, Zalo, Facebook).

## Cấu trúc
- `index.html`: markup trang, chia section Giới thiệu/Phòng/Dàn di động/Liên hệ.
- `style.css`: phong cách tổng thể, hiệu ứng hover/scroll, màu chuyển sắc.
- `grid.css`: hệ thống grid tự xây cho responsive.
- `js.js`: toggle sidebar, hiệu ứng hiện dần và slideshow phòng.
- `source/`: ảnh, biểu tượng, asset tĩnh.

## Chạy cục bộ
1) Mở thư mục `d:\tmp2\karaoke\`.
2) Dùng live server hoặc mở trực tiếp `index.html` trên trình duyệt.

## Ghi chú triển khai
- Đang được triển khai tại **https://karaoketinnguyen.id.vn/**.
- Không phụ thuộc backend; chỉ cần host tĩnh là hoạt động.
